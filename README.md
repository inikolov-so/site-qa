# site-qa
Проверка на всеки наш сайт на истински Windows (Chrome, Edge), Android и iPhone. Скилът е `cross-device-qa` в ai-os.
Детекторът е `checks/checks.js`: мери мастилото на буквите, изрязване, застъпване, хоризонтален скрол, шрифтове, грешки.

Пълен кръг: `./qa.sh <папка на сайта>` (Windows Chrome и Edge, iPhone, Android). Печата номерата на кръговете.
Резултатите: `./get.sh <номер> [<номер>]` → `out/<номер>/`.

**Репото е публично** (от 11.11.2026), за да са машините на GitHub безплатни без лимит. Затова пакетът на сайта
и резултатите (снимки, отчети) са шифровани с AES-256: ключът е в `~/.config/site-qa/key` на Мак Мини-то и в
тайната `QA_KEY` на репото. Без ключа releases и артефактите не се отварят. В логовете има само числа.
Старите кръгове (до 10.11, нешифровани) са в частното `inikolov-so/site-qa-archive`.
Само колелото на Windows: `gh workflow run detent.yml -f bundle=<таг>`.
Локално: `tests/detent_test.py` (колело), `tests/touch_test.py` (пръст през DevTools).
